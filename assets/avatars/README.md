# Avatars (GLB)

Drop **Mixamo-compatible** `.glb` files here for Ops Console 3D preview.

## Recommended

- Rig: Mixamo humanoid
- Morphs (best lip preview): **Oculus visemes** (`viseme_aa`, `viseme_oh`, …) and/or **ARKit** (`jawOpen`, `mouthPucker`, …)
- Export path: VRoid → Blender (TalkingHead docs) → GLB, or Ready Player Me GLB

## Honesty

- Mesh preview + rule-based morph driving ≠ HeyGen photoreal
- Without morph targets, Speak still animates a procedural mouth (or slight scale on the whole GLB)
- Files stay local under `assets/avatars/` — not uploaded anywhere by the engine
